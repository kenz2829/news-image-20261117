## Overview
A deterministic Python program that writes an editorial visual summary of major global news events from November 17, 2026, to `/output/entry.png`.

## Highlights Covered
- Diplomatic summits in Asia (ASEAN & Shenzhen trilateral talks)
- Kerch Strait Bridge damage and security escalation
- Maritime tensions in the Strait of Hormuz
- Global technology outages and semiconductor market volatility
